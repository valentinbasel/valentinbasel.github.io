SATURAR es una herramienta diseñada para sistematizar la recolección, codificación y lectura de datos textuales o de videos, 
para su uso en procesos enmarcados dentro de los paradigmas cualitativos interpretativos de investigación, 
comúnmente usado en las ciencias sociales. Esta herramienta nos permite trabajar con metodologías de investigación 
como la teoría fundamentada mediante la codificación de textos para poder obtener reportes textuales, capturas de 
pantallas de videos, así como la posibilidad de procesar de forma estadística mediante el uso de el lenguaje de 
programación PYTHON y la librería saturapi

[saturar - Software para analisis de datos cualitativo](https://saturar.conicet.unc.edu.ar/)
